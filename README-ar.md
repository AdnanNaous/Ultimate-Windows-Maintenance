## 📝 الوصف
تجمع الأداة مهام الصيانة في وحدات PowerShell. لا تضمن فحوصات الصياغة سلامة التشغيل، ولا تغني نقطة استعادة النظام عن النسخ الاحتياطي للملفات.

## ✨ المميزات
- **فحص صحة النظام:** التحقق من إصدار النظام، صحة الأقراص (SMART)، حالة الذاكرة، والأخطاء الحرجة في سجل الأحداث. *(الوقت المقدر: 1-2 دقيقة)*
- **تنظيف النظام:** تنظيف الملفات المؤقتة بشكل آمن، ذاكرة التخزين المؤقت لتحديثات ويندوز، ذاكرة DirectX، وإفراغ سلة المهملات بذكاء وتجاوز الملفات المقفلة. *(الوقت المقدر: 1-3 دقائق)*
- **إصلاح النظام:** أتمتة أوامر الإصلاح العميقة (`sfc /scannow` و `DISM RestoreHealth`) وتنظيف متجر المكونات (Component Store) مع إدارة صارمة لوقت التشغيل. *(الوقت المقدر: 5-20 دقيقة)*
- **التحديثات:** تشغيل تحديثات ويندوز، ترقية البرامج باستخدام `winget`، وتحديث إضافات PowerShell. *(الوقت المقدر: 3-10 دقائق)*
- **التعريفات:** اكتشاف تعريفات AMD و NVIDIA و Intel بأمان تام دون حذفها أو فرض تثبيتها. *(الوقت المقدر: أقل من 10 ثوانٍ)*
- **الأمان:** تحديث قواعد بيانات Microsoft Defender، إجراء فحص بالخلفية، وعزل التهديدات النشطة فوراً. *(الوقت المقدر: 2-30 دقيقة، بناءً على نوع الفحص السريع أو الشامل)*
- **التوافق مع G-Helper:** اكتشاف حالة تطبيق G-Helper وعمل نسخة احتياطية آمنة لإعداداته. *(الوقت المقدر: أقل من 5 ثوانٍ)*
- **التقارير:** إنشاء تقارير شاملة بعد كل عملية صيانة بصيغ JSON و TXT و HTML. *(الوقت المقدر: أقل من 5 ثوانٍ)*

## 🏷️ الإصدار
- **الإصدار الحالي:** v1.0.2
- **التحقق:** افحص نتائج سير العمل للصياغة؛ يتطلب اختبار الصيانة بيئة ويندوز منفصلة قابلة للاستعادة.

## 🔄 سجل التغييرات
**v1.0.2 - دعم معالجات وكروت شاشة Intel**
- إضافة القدرة على اكتشاف كروت الشاشة المدمجة والمنفصلة من Intel.
- إضافة توصية باستخدام برنامج تحديث تعريفات إنتل الرسمي (Intel DSA).

**v1.0.1 - إصلاح الأخطاء وتحديث التوثيق**
- إصلاح خطأ استدعاء (COM Exception) عند تنظيف سلة المهملات.
- إضافة الأوقات المقدرة لكل خطوة في ملفات الشرح.

**v1.0.0 - الإصدار الأولي**
- إعادة بناء الكود بالكامل بمعايير هندسية احترافية.
- إضافة دالة `Invoke-SafeOperation` للتشغيل الآمن وتفادي الأخطاء.
- إنشاء نقاط استعادة للنظام (Restore Point) بشكل تلقائي قبل بدء الصيانة.

## 📚 دليل الاستخدام
### المتطلبات
- **نظام التشغيل:** ويندوز 11
- **الطرفية:** PowerShell 7 أو أحدث
- **الصلاحيات:** يجب تشغيل الطرفية بصلاحيات المسؤول (Administrator).

### طريقة التشغيل
1. افتح **PowerShell 7** بصلاحيات المسؤول (Run as Administrator).
2. قم بتحميل أو استنساخ المشروع إلى جهازك.
3. انتقل إلى مجلد الأداة من خلال سطر الأوامر.
4. قم بتشغيل السكربت عبر الأمر التالي:
   ```powershell
   .\Start-Maintenance.ps1
   ```

### 🛠️ حل المشاكل: هل يرفض السكربت العمل؟
إذا قام نظام ويندوز بحظر السكربت وأظهر لك خطأ باللون الأحمر (مثل "not digitally signed" أو "cannot be loaded")، فهذا بسبب سياسة الأمان (Execution Policy) في PowerShell التي تمنع الملفات المحملة من الإنترنت. تحقق من المصدر وراجع السكربتات أولاً. يتجاوز الأمر التالي فحوصات سياسة التنفيذ لهذه العملية فقط ولا يثبت سلامة السكربت؛ استخدمه فقط بعد فهم تغييرات النظام والموافقة عليها:
```powershell
pwsh.exe -ExecutionPolicy Bypass -File .\Start-Maintenance.ps1
```

الخطأ واضح من الصورة.

أنت الآن داخل:

```text
C:\Windows\System32
```

وأنت كتبت:

```powershell
pwsh.exe -ExecutionPolicy Bypass -File .\Start-Maintenance.ps1
```

لكن الملف **ليس موجودًا داخل System32**، لذلك PowerShell أعطاك:

> `.\Start-Maintenance.ps1` is not recognized as the name of a script file

## الحل الأول (الأفضل)

اذهب أولًا إلى المجلد الذي يوجد فيه السكربت.

مثلاً إذا كان داخل:

```text
C:\Projects\Ultimate-Windows-Maintenance
```

نفذ:

```powershell
cd "C:\Projects\Ultimate-Windows-Maintenance"
```

ثم:

```powershell
pwsh -ExecutionPolicy Bypass -File .\Start-Maintenance.ps1
```

## الحل الثاني

شغله مباشرة بالمسار الكامل:

```powershell
pwsh -ExecutionPolicy Bypass -File "C:\Projects\Ultimate-Windows-Maintenance\Start-Maintenance.ps1"
```

(غيّر المسار إذا كان الملف في مكان آخر.)

## إذا لا تعرف أين يوجد الملف

ابحث عنه بالأمر:

```powershell
Get-ChildItem C:\ -Filter Start-Maintenance.ps1 -Recurse -ErrorAction SilentlyContinue
```

أو إذا تعرف المجلد تقريبًا:

```powershell
Get-ChildItem "C:\Projects" -Filter Start-Maintenance.ps1 -Recurse
```

### أريد التأكد من مكان الملف

نفذ هذا الأمر وأرسل الناتج:

```powershell
Get-ChildItem "C:\Projects" -Recurse -Filter Start-Maintenance.ps1
```

إذا لم يظهر شيء، فأخبرني أين خزنت مشروع **Ultimate-Windows-Maintenance** أو أرسل لقطة شاشة لمحتويات المجلد، وسأعطيك الأمر الصحيح مباشرة.

> [!WARNING]
> **احفظ عملك أولاً:** افتراضياً، ستقوم الأداة **بإعادة تشغيل حاسوبك تلقائياً** عند انتهاء الصيانة (مع عد تنازلي لمدة 30 ثانية) لتفريغ الذاكرة وتطبيق إصلاحات النظام. يرجى حفظ جميع أعمالك وإغلاق البرامج المفتوحة قبل تشغيل السكربت!

> [!WARNING]
> **تحذير هام:** لا تقم بفتح ملف `.ps1` ونسخ الكود ولصقه مباشرة داخل نافذة PowerShell. يجب تشغيل السكربت كملف باستخدام الأمر أعلاه حتى يتمكن من العثور على الإعدادات والمجلدات الخاصة به!

*(ملاحظة: إذا أردت تخطي إنشاء نقطة استعادة النظام لتوفير الوقت، يمكنك استخدام الأمر `-SkipRestorePoint`)*
